# 🚀 Admin Dashboard

A modern and fully responsive Admin Dashboard built with **React** and **Tailwind CSS**. This project focuses on creating a clean dashboard interface with reusable components and a responsive user experience across mobile, tablet, and desktop devices.

## ✨ Features

* 📊 Dashboard with summary cards
* 📈 Sales analytics chart
* 👥 Users management page
* 🔍 User search functionality
* 📦 Products page
* ⚙️ Settings page
* 📱 Fully responsive design
* 🎨 Clean and modern UI
* 🧩 Reusable React components

## 🛠️ Tech Stack

* React
* React Router DOM
* Tailwind CSS
* Lucide React
* Recharts

## 📸 Pages

* Dashboard
* Users
* Products
* Settings

## 🚀 Getting Started

```bash
npm install
npm run dev
```
